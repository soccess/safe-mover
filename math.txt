## 수정 핵심

### 1. 메뉴 = 실제 활동
- 기존에는 계산기가 먼저 보이고 단계별 교구가 아래에 숨어 있었습니다.
- 이제 코스를 고르면 **활동 화면이 기본**으로 열리고, 단계를 선택하면 해당 활동으로 바로 이동합니다.
- 상단에 `?? 활동 / ?? 계산기` 전환을 추가해 계산기는 보조 도구로 사용할 수 있습니다.
- `?? 12개 활동 모두 보기` 버튼으로 12단계 전체에 바로 접근할 수 있습니다.

### 2. 12개 활동 전부 터치 드래그 구현
| 단계 | 터치 드래그 활동 |
|---|---|
| 1 분류 | 과일을 바구니로 끌어다 놓기 |
| 2 세기 | 점을 10칸 판에 끌어 놓기, +10·+100 |
| 3 비교 | 점을 양쪽 접시로 끌어 비교 |
| 4 모으기·가르기 | 점을 칸 사이로 끌어 옮기기 |
| 5 10 만들기 | 오른쪽 점을 왼쪽 빈칸으로 끌기 |
| 6 전략 | 수직선 위 개구리 표식을 목표 자리로 끌기 |
| 7 자릿값 | 일·십·백 수모형을 자리 칸으로 끌기, 10개·100개 묶기 존 |
| 8 곱셈·나눗셈 | 묶음 카드를 그룹으로, 점을 접시로 끌기 |
| 9 분수 | 분수 조각을 막대로 끌기 |
| 10 측정 | 연필·물 높이·무게추·시계바늘·동전 끌기 |
| 11 도형 | 도형을 보드로 끌고 두 번 눌러 회전, 규칙 무늬 끌기 |
| 12 자료 | 과일을 그래프 위로 끌기, 이야기 문제 바구니 |

### 3. 10개·100개 묶기
- 상단 `?? 10·100 묶기` 버튼으로 전용 묶음 놀이를 열 수 있습니다.
- 100칸 판에 점을 끌어 놓고 **10개 묶기 → 십 1개**, **100개 묶기 → 백 1개**로 직접 변환합니다.
- 7단계 수모형, 2단계 세기, 8단계 곱셈, 10단계 화폐 등에도 10·100 묶기 버튼을 넣었습니다.

### 4. 미국 특수교육 지침 반영
도움말에 근거와 함께 정리했습니다.
- **NCAEP/AFIRM 28개 근거기반 실제**: 시각적 지원, 촉진, 강화, 과제분석, 기다림 시간, 모델링, 자기관리, AAC, 테크놀로지 기반 교수
- **CEC High-Leverage Practices**: 명시적·체계적 교수, 비계, 보조공학, 진행 점검
- **WWC(2021) 수학 중재**: 체계적 교수, 시각적 표상, 수직선
- **CRA**: 구체물 → 그림 → 숫자·기호
- **UDL 3.0**, **WCAG 2.2**, **TEACCH 구조화 교수**, **NCII 데이터 기반 개별화**

### 5. 특수교육 지원 기능
- 시각적 일정 · 먼저-다음 보드
- 칭찬 별 토큰 보드 · 보상 선택
- 도움 수준(스스로 → 보고 → 듣고 → 같이 → 도움) 프롬프트 위계
- 오류 없는 학습(정답 자리 미리 표시), 기다림 시간, 자동 힌트
- 쉬는 시간 타이머 · 호흡 원
- AAC 말판(도와주세요, 더, 그만, 또, 쉬고 싶어요 등)
- 스스로/도움 받았어요 자기점검, 시도·독립 수행 기록, CSV 저장
- 큰 터치, 글자 크게, 고대비, 동작 줄이기, 쉬운 말 설정
- 음성 안내 + 실시간 자막(live region)

## 검증
- Playwright로 **12개 단계 전체 렌더링·드래그·설정·다이얼로그**를 테스트했습니다.
- 320px / 390px / 768px 모바일 화면에서 가로 넘침 없음.
- 콘솔 오류 없음.
