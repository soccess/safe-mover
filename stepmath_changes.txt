stepmath.html 변경 내역 (미국 특수교육 명시적 교수법 기반 개편)

1. 교수 구조 개편: 예시 문제 → 직접 풀기 (Explicit Instruction: I Do → You Do)
- 기존에는 상단의 단계(먼저 보기/같이 해보기/혼자 해보기)를 눌러도 아래 교구 화면이 변하지 않고 자유 탐색 위주로만 동작하던 문제를 개선했습니다.
- 모든 12단계(1~12단계) 상단에 '1. 👀 예시 문제 보기'와 '2. ✏️ 직접 문제 풀기' 전환 탭 및 전용 카드를 추가했습니다.
- '예시 문제 보기'에서는 문제, 구체물 시각 자료, 3단계 풀이 과정, 음성 설명 듣기(🔊)를 먼저 확인한 뒤 '이제 내가 풀어볼까요?' 버튼으로 문제 풀기로 넘어갑니다.

2. 전 단계(1~12단계) 맞춤형 예시 문제 및 3단계 연습 문제(총 36문항) 탑재
- 1단계(짝짓기와 분류): 예시(사과·레몬 분류) + 바구니 분류 실습 2문항, 개수 세기 1문항
- 2단계(하나씩 세어보기): 예시(일대일 대응 5세기) + 10칸 판 채우기(6개, 10개), 수 세기(8개)
- 3단계(수의 순서와 크기): 예시(6 vs 4 짝짓기 비교) + 크기 비교(5>3, 4<7), 양쪽 같게 맞추기(6=6)
- 4단계(모으기와 가르기): 예시(3+5=8 모으기) + 덧셈(2+4, 5+3) 및 뺄셈(7-2)
- 5단계(10 만들어 계산하기): 예시(7+5 → 10+2=12) + 10 만들기 빈칸(8+?=10), 8+4, 9+5
- 6단계(덧셈·뺄셈 전략): 예시(수직선 8+4 점프) + 수직선 점프 이동(6+3=9), 뺄셈 점프(9-4), 덧셈(7+5)
- 7단계(자릿값과 세로식): 예시(일 모형 12개 → 십 모형 1개 묶음=32) + 수 만들기(24), 십·일 묶음 이해(12), 받아올림 덧셈(24+18)
- 8단계(묶음 곱셈과 나누기): 예시(3개씩 4묶음=12) + 뛰어 세기(2×4), 묶음 만들기(3×3), 똑같이 나누기(8÷2)
- 9단계(분수와 소수): 예시(1/4 + 2/4 = 3/4) + 분수 막대 색칠하기(3/4), 분수 덧셈, 소수 변환(5/10=0.5)
- 10단계(측정하기): 예시(자 10cm, 시계 3시, 동전 150원) + 자 눈금 7cm 맞추기, 시계 읽기(3시 30분), 동전 150원 만들기
- 11단계(도형과 규칙성): 예시(세모 변 3개, 반복 무늬) + 도형 특징 찾기(사각형), 규칙 찾기, 도형 보드 세모 2개 놓기
- 12단계(자료와 문제해결): 예시(막대그래프 비교) + 가장 많은 과일 찾기, 그래프 개수 늘리기(바나나 6개), 이야기 문제(3+5=8)

3. 특수교육 학습 지원 기능 연동
- 쉬운 말 모드(설정) ON 시 문제 문장이 자동으로 쉬운 문장으로 전환됩니다.
- 오답 시 부정적 피드백 대신 부드러운 격려와 힌트를 자동 표시하며, 정답 시 칭찬 별(토큰) 지급 및 교사용 리포트(시행 기록/정답/도움/오류)에 자동 기록됩니다.
- 교구 조작형 문제('tool')와 선택형 문제('choice')를 모두 지원하며, 문제마다 교구 상태가 자동으로 맞춰집니다.
